# Jarvis Response Reference Manual

## Overview
This document serves as the comprehensive reference guide for all standard user commands, intents, and corresponding spoken response outputs generated by the Local Response System.

---

## Response Reference Matrix

### 1. Conversational & Basic Intents

| User Input Phrase | Recognized Intent | Spoken Response Output |
|---|---|---|
| `"Jarvis"`, `"Hey Jarvis"` | `wake_response` | `"Yes?"` / `"I'm listening."` / `"Go ahead."` |
| `"Hello"`, `"Hi Jarvis"` | `greeting` | `"Hello."` / `"Hello! How can I help?"` |
| `"Namaste Jarvis"` | `greeting` | `"Namaste."` / `"Namaste! How can I help?"` |
| `"Good morning"` | `greeting` | `"Good morning! How can I help?"` |
| `"Thank you"`, `"Thanks"` | `thank_you` | `"You're welcome."` / `"Anytime."` |
| `"Goodbye"`, `"Bye"` | `goodbye` | `"Goodbye."` / `"See you later."` |
| `"Who are you?"` | `identity` | `"I'm Jarvis, your personal desktop assistant."` |
| `"Help"`, `"What can you do?"` | `help` | `"I can open applications, manage your computer, control volume, open folders and websites, take screenshots, and execute multiple commands."` |

### 5. Multi-Command Chain Examples

| User Input Phrase | Sub-Commands Executed | Combined Spoken Response |
|---|---|---|
| `"Close Calculator and volume up"` | 1. close calculator<br>2. volume up | `"Done. Closing Calculator., and Volume increased."` |
| `"Take a screenshot and lock computer"` | 1. take screenshot<br>2. lock computer | `"Done. Screenshot saved., and Locking the computer."` |

### 6. Sanitized Error Outputs

| Technical Exception / Log Error | User-Facing Spoken Response |
|---|---|
| Database Connection Error / Stack Trace | `"I couldn't complete that."` |
| Unregistered Application Target | `"I couldn't find that application."` |
| Unsupported OS Capability | `"That action isn't supported on this system."` |
