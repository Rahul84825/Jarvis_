# Response System & Conversational Templates — Project Jarvis

## Overview
The `ResponseManager` formats concise, natural language spoken responses with variation templates for all assistant interactions.

---

## Conversational Voice Templates

| Interaction Category | Spoken Templates Pool |
| :--- | :--- |
| **Wake Word Trigger** | `"Yes?"`, `"How can I help?"`, `"At your service."`, `"Yes, I'm listening."` |
| **App Launch Success** | `"Opening {app}."`, `"Sure. Opening {app}."`, `"Got it. Launching {app}."` |
| **Screenshot Success** | `"Done. Screenshot saved."`, `"Got it. Screenshot captured."` |
| **Volume Adjustment** | `"Volume increased."`, `"Volume decreased."`, `"Volume muted successfully."` |
| **System Power Action** | `"Computer locked successfully."`, `"Putting computer to sleep."` |
| **Command Failure** | `"I couldn't complete that."`, `"I ran into a problem completing that request."` |
| **Unrecognized Input** | `"I'm not sure what you meant."` |
| **Offline Question Fallback**| `"I'm currently operating in offline mode, so I can't provide my full AI response for that question right now."` |
